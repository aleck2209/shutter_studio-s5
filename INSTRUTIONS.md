## Texte

### Titre

- Titre de section
  - Font-size : 2rem ;
  - Font-family : utiliser la variable --font-title ;
  - Font-weight : 700 ;

### Texte

- Texte normal
  - Font-size :1rem ;
  - Font-family : utiliser la variable --font-text
  - Font-weight : 400 ;
- Texte bouton
  - Font-size :1rem ;

## Espacement

Pour chaque section de la main, respecter ceci :

- Margin : ajouter un margin bottom : 2rem ;
- Padding : 2rem 4rem ;

Faire du mobile-first : en autre styliser d'abord pour le mobile et ensuite passé à la tablette après au pc.

### Mobile
